## 🖨️ 转换为PDF

### 方法一：浏览器打印（推荐）

1. **打开文件**
   ```bash
   # 在浏览器中打开
   firefox 不一致标注报告_20251029_184122.html
   # 或
   google-chrome 不一致标注报告_20251029_184122.html
   ```

2. **打印为PDF**
   - 按 `Ctrl+P` (Linux/Windows) 或 `Cmd+P` (Mac)
   - 目标打印机选择: **另存为PDF**
   - 纸张大小: **A4**
   - 边距: **无** 或 **最小**
   - 背景图形: **启用**
   - 点击"保存"

3. **保存位置**
   - 选择保存路径
   - 建议文件名: `任务4_标注不一致报告.pdf`

### 方法二：使用Chrome无头模式（命令行）

创建转换脚本：

```bash
#!/bin/bash
# 文件名: convert_to_pdf.sh

INPUT_HTML="不一致标注报告_20251029_184122.html"
OUTPUT_PDF="任务4_标注不一致报告.pdf"

google-chrome --headless \
  --disable-gpu \
  --print-to-pdf="$OUTPUT_PDF" \
  --print-to-pdf-no-header \
  --no-margins \
  "$INPUT_HTML"

echo "✅ PDF已生成: $OUTPUT_PDF"
```

执行：
```bash
chmod +x convert_to_pdf.sh
./convert_to_pdf.sh
```

### 方法三：使用wkhtmltopdf

```bash
# 安装 (如果未安装)
sudo apt-get install wkhtmltopdf

# 转换
wkhtmltopdf \
  --page-size A4 \
  --enable-local-file-access \
  --no-outline \
  不一致标注报告_20251029_184122.html \
  任务4_标注不一致报告.pdf
```
