## 🖨️ **使用方法**

### **方法一：在浏览器中查看**

```bash
# 打开HTML文件
firefox 完整标注报告_20251029_184930.html

# 或使用Chrome
google-chrome 完整标注报告_20251029_184930.html

# 或使用默认浏览器
xdg-open 完整标注报告_20251029_184930.html
```

### **方法二：转换为PDF**

#### **使用提供的脚本（推荐）**

```bash
./转换为PDF.sh
```

脚本会自动：
1. 检测Chrome/Chromium浏览器
2. 转换HTML为PDF
3. 生成 `任务4_完整标注报告_50张.pdf`

#### **手动转换**

在浏览器中打开HTML后：
1. 按 `Ctrl+P` (Linux/Windows) 或 `Cmd+P` (Mac)
2. 选择"另存为PDF"
3. 纸张大小：A4
4. 边距：无
5. 启用"背景图形"
6. 保存
